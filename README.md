# 🎯 个人工作台

> 一个简洁优雅的个人成长追踪系统，支持任务管理、文档库、数据统计和 PWA 离线使用。

---

## ✨ 功能特性

### 📋 任务管理
- **四大板块**：口才训练、专业沉淀、运动健身、思维训练
- **多视图**：看板视图、列表视图、时间轴视图
- **任务追踪**：完成状态、进度统计、连续打卡

### 📝 文档库
- 按板块分类管理文档
- 支持观点提取（①②③编号格式）
- 个人见解记录
- 标签系统

### 📊 数据看板
- 今日完成率
- 连续打卡天数
- 近7天趋势图
- 各板块进度条
- 成就系统（9种成就徽章）

### ✨ AI 辅助
- 内容搜索
- 观点提炼
- 见解生成

### ⚙️ 个性化
- 深色/浅色主题
- 自定义任务
- 数据导入/导出

### 📱 PWA 支持
- 添加到桌面
- 离线使用
- 推送通知

## 💾 数据存储

所有数据保存在浏览器本地（localStorage），包括：
- 任务完成记录
- 文档库内容
- 用户设置
- 成就解锁状态

⚠️ **注意**：清除浏览器数据会丢失所有记录，建议定期导出备份。

---

## 📱 移动端使用

1. 部署到 Vercel 获得访问链接
2. 手机浏览器打开链接
3. 添加到主屏幕
4. 像原生 APP 一样使用！
